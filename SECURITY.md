# Security policy

## Report a vulnerability

Do not open a public issue for a security problem.

Report it with GitHub private vulnerability reporting:

1. Open the **Security** tab of this repository.
2. Select **Report a vulnerability**.
3. Describe the problem. Include the steps to repeat it.

We answer within 7 days. We fix confirmed problems in the next release.

## Scope

In scope:

- The server code in `log_triage/`.
- The `Dockerfile` and the workflows in `.github/`.

Out of scope:

- The OpenEnv framework. Report those problems to the OpenEnv project.
- The Hugging Face arena service. Report those problems to the arena operators.
